A horror vehicle where players pull blocks from a Jenga tower instead of rolling! If the tower falls your character dies!

I've been interested in this game for a long time, but I've never brought it to the table mostly because it's hard to build a table. My spooky friends are mostly online, and I'm not really sure how to translate the central Jenga mechanic to an online experience. Here's some ideas I've had:

- Use an online tabletop software with an actual block tower.
  - This exists but I'm not sure if the difficulty would be the same.
- Use a competitive online Minesweeper software.
  - Give players 30 seconds to click X tiles on the board.
    - Or maybe have them find X mines in 30 seconds?
  - I'm not sure if the software I need exists out of the box, I might need to build something.
